# mapping-health-ai-repositories
A graph-analytics study of public code repositories related to health AI, revealing how collaborative communities are organized across subfields.

This code was used for a research paper entitled "Mapping Open-Source Health AI: A Graph-Analytics Study Across Imaging, EHR, Genomics, and General Clinical Applications" presented at the International Conference on Multidisciplinary Perspectives in Advanced Computing and Technology, January 10-11 2026 (IMPACT 2026). The official citation and DOI are to come shortly.
