# mapping-health-ai-repositories
A graph-analytics study of public code repositories related to health AI, revealing how collaborative communities are organized across subfields.

This code was used for a research paper presented at the International Conference on Multidisciplinary Perspectives in Advanced Computing and Technology, January 10-11 2026 (IMPACT 2026).

Published version of the paper in the conference proceedings:  
*Baddour, R. (2026) “Mapping Open-Source Health AI: A Graph-Analytics Study Across Imaging, EHR, Genomics, and General Clinical Applications”, DMPedia Lecture Notes in Multidisciplinary Research, (IMPACT26), pp. 958–969. Available at: https://digitalmanuscriptpedia.com/conferences/index.php/DMP-LNMR/article/view/49*
